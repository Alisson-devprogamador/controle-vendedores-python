# Controle de Vendedores em Python

Projeto desenvolvido em Python utilizando conceitos de Programação Orientada a Objetos (POO).

## Funcionalidades
- Cadastro de vendedores
- Controle de metas
- Verificação de desempenho
- Manipulação de dados utilizando classes e objetos

## Tecnologias utilizadas
- Python
- Programação Orientada a Objetos
